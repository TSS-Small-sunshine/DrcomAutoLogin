# 02 - 国产 ROM 保活指引（必读）

> ⚠️ **适用范围**：本项目默认配置与实测环境为**福建农业职业技术学院**校园网；其它学校需自行确认网关地址与协议。

> **这一篇是三个文档里最重要的一个。**
> 如果你只想做一件事：**照着你这台手机品牌的章节，把自启动和省电策略配好。** 别的可以不做，这个不做，自动登录等于白装。

---

## 先搞懂：什么叫「保活」

安卓系统为了省电，会在你**退到桌面、锁屏、或者内存紧张的时候**，把后台的 App 悄悄「冻结」或「杀掉」。这是所有安卓手机的通病，但国产 ROM（小米/华为/OPPO/vivo 等）下手特别狠——它们为了续航和流畅度，额外加了一套自己的后台管控。

结果就是：**你打开 App 时它能登录，一划掉就再也不动了。**

所谓「保活」就是告诉系统：「**这个 App 别杀，我需要它一直在后台待命。**」

具体要做 4 类设置：

| 类别 | 作用 | 不做会怎样 |
| --- | --- | --- |
| ① 自启动 | 允许 App 开机后自动运行 | 重启手机后不会自动登录 |
| ② 省电策略 / 后台活动 | 允许 App 长期在后台活动 | 过一会儿就不检查了，掉线不重连 |
| ③ 电池优化 | 把 App 列入「不优化」白名单 | 系统在息屏后限制它的网络和定时任务 |
| ④ 任务列表锁定 | 防止「一键清理」把它清掉 | 每次清后台都把它杀掉 |

App 自己也有两个开关配合：**「常驻通知保活」** 和 **「打开电池优化设置」** 按钮，见本文最后一节。

## 小米 / 红米（MIUI / 澎湃 HyperOS）

这是管控最严的一家，请把 4 项都做完。

### 1. 打开自启动、省电策略、后台弹出界面

> 大致路径（各版本略有差异）：设置 → 应用设置 → 应用管理 → Dr.COM 校园网自动登录

1. 打开 **`设置`**。
2. 找到 **`应用设置`**（部分版本叫 `应用`）。
3. 点 **`应用管理`**。
4. 在列表里找到并点开 **`Dr.COM 校园网自动登录`**。
5. 点 **`权限管理`**：
   - 把 **`自启动`** 打开（变成蓝色/开启状态）。
   - 进入 **`其他权限`**，把 **`显示悬浮窗`**（部分版本叫 `后台弹出界面`）打开。
6. 返回到 App 详情页，点 **`省电策略`**（部分版本叫 `电池` / `耗电管理`）：
   - 选择 **`无限制`**。
   - **不要**选「智能限制」或「优化」。
7. （可选但推荐）在 App 详情页点 **`通知管理`**，确认「允许通知」是打开的。

### 2. 锁定最近任务卡片

> 大致路径：从屏幕底部上滑（或按方形多任务键）进入最近任务界面

1. 打开最近任务界面，找到 **`Dr.COM 校园网自动登录`** 的卡片。
2. **长按**这张卡片。
3. 点出现的 **`🔒 锁形图标`**（有的版本叫 `加锁` / `锁定`）。
4. 卡片右上角出现一个小锁图标 = 成功。

这样你点「一键清理」时，它不会被清掉。

### 3. 关闭系统的「省电模式」

> 大致路径：设置 → 电池 → 省电模式 / 超级省电

省电模式开启时，所有 App 的后台活动都会被限制。**该模式下自动登录基本不会工作**，用的时候记得关掉。

### 4. 神隐模式（老版 MIUI 才有）

老版本 MIUI 有「神隐模式」，路径大致是：`设置` → `电池与性能` → `神隐模式` → 找到本 App → 选 **`无限制`**。

> 💡 小米的坑：MIUI 的「自启动」在**覆盖安装 App 后**有时会被重置。每次更新 App 后，回来确认一下。

## 华为 / 荣耀（EMUI / HarmonyOS / MagicOS）

### 1. 手动管理启动

> 大致路径：设置 → 应用 → 应用管理 → Dr.COM 校园网自动登录 → 耗电详情

1. 打开 **`设置`**。
2. 点 **`应用`** → **`应用管理`**（荣耀可能叫 `应用和服务` → `应用管理`）。
3. 找到并点开 **`Dr.COM 校园网自动登录`**。
4. 点 **`耗电详情`**（有的版本叫 `电池` / `功耗管理`）。
5. 找到 **`应用启动管理`**：
   - 先把右上角或顶部的 **`自动管理`** **关闭**。
   - 关闭后会出现 3 个开关，**全部手动勾选**：
     - ☑ **`允许自启动`**
     - ☑ **`允许关联启动`**
     - ☑ **`允许后台活动`**
   - 点 `确定`。**这里必须关闭「自动管理」，否则系统会把你勾的选项自动改回去。**

### 2. 手机管家里的启动管理

> 大致路径：手机管家 → 应用启动管理

1. 打开 **`手机管家`**（有的版本叫 `华为手机管家`）。
2. 点 **`应用启动管理`**。
3. 找到 **`Dr.COM 校园网自动登录`**，同样关闭「自动管理」，手动勾选上面那 3 项。

### 3. 休眠时保持网络连接

> 大致路径：设置 → 电池 → 更多电池设置

找到 **`休眠时始终保持网络连接`**，把它 **打开（开启）**。

这样手机息屏休眠时 WiFi 不会被断开，App 才能定时检查（如果关着，息屏后等于断网，定时检查必然失败）。

### 4. 关闭「省电模式」

设置 → 电池，确认没有开启省电模式/超级省电。

### 5. 锁定最近任务

多任务界面 → 下拉 App 卡片（华为是**下拉**卡片出现锁图标）→ 点锁图标。

## OPPO / 一加 / realme（ColorOS / OxygenOS）

> 大致路径：设置 → 应用 → 应用管理 → Dr.COM 校园网自动登录 → 耗电管理

1. 打开 **`设置`**。
2. 点 **`应用`** → **`应用管理`**（ColorOS 12+ 可能叫 `应用` → `应用列表`）。
3. 找到并点开 **`Dr.COM 校园网自动登录`**。
4. 点 **`耗电管理`**（有的版本叫 `电池` → `应用耗电管理`）。
5. **把下面这几项全部打开**：
   - ☑ **`允许完全后台行为`**（最关键的一项）
   - ☑ **`允许自启动`**
   - ☑ **`允许关联启动`**
   - ☑ **`允许后台活动`**
6. 如果看到 **`智能省电` / `智能后台冻结`** 之类的开关，也一并关闭或设为「不限制」。

### 锁定最近任务卡片

1. 进入最近任务界面（上滑停顿，或按多任务键）。
2. 找到本 App 的卡片。
3. 点卡片右上角的 **`⋮`（三个点）** 或 **长按卡片**。
4. 选 **`锁定`**。卡片上会出现锁图标。

### 其他

- 设置 → 电池 → 关闭 **`省电模式`** / **`超级省电模式`**。
- 设置 → 电池 → **`更多设置`** → 关闭 **`睡眠待机优化`**（如果该 ROM 版本有这个选项）。

## vivo / iQOO（OriginOS / Funtouch）

### 1. 打开自启动

> 大致路径：设置 → 应用与权限 → 权限管理 → 自启动

1. 打开 **`设置`**。
2. 点 **`应用与权限`**（Funtouch 可能叫 `更多设置` → `权限管理`）。
3. 点 **`权限管理`**。
4. 找到 **`自启动`**（在权限列表里，可能需要左右滑动或点「权限」标签）。
5. 在列表里把 **`Dr.COM 校园网自动登录`** 的开关 **打开**。
   - 部分版本这里有「**允许自启动**」和「**允许后台启动**」两个开关，都打开。

### 2. 允许后台高耗电

> 大致路径：设置 → 电池 → 后台高耗电

1. **`设置`** → **`电池`**（Funtouch 在 `设置` → `更多设置` → `电池`）。
2. 点 **`后台高耗电`** / **`后台耗电管理`**。
3. 找到 **`Dr.COM 校园网自动登录`**，设为 **`允许`**（或把它加入「允许后台高耗电」列表）。

### 3. i 管家（vivo 自家的手机管家）

> 大致路径：i 管家 → 应用管理 → 权限管理 → 自启动

1. 打开 **`i 管家`**（桌面上的橙色图标）。
2. 点 **`应用管理`** → **`权限管理`** → **`自启动`**。
3. 打开本 App 的开关。

### 4. 锁定最近任务

1. 进入最近任务界面。
2. 长按本 App 卡片（或点卡片右上角 `⋮`）。
3. 选 **`锁定`**。

### 5. 注意

vivo 的 **`省电模式`** 和 **`超级省电`** 一定要关。另外部分 Funtouch 版本有「**应用冻结**」功能，要在 `设置` → `应用与权限` → `应用冻结` 里确认本 App **不在**冻结列表中。

## 通用三步（所有国产 ROM 都建议做）

不管什么品牌，下面这 3 步都建议做一遍。

### 第 1 步：把 App 加入「电池优化」白名单

1. 打开 **`设置`**，在顶部的**搜索框**里搜 **`电池优化`**。
2. 进入电池优化（或叫「电池优化」「优化电池使用」「应用节能」）页面。
3. 把筛选从「未优化」切到 **`所有应用` / `全部`**（很多 ROM 默认只显示「未优化」的应用，找不到本 App 就是这个原因）。
4. 找到 **`Dr.COM 校园网自动登录`**，点它，选择 **`不优化`**（或「允许」「不限制」）。
5. 确认对话框。

> 💡 **更快的办法**：直接在 App 里点 **`打开电池优化设置`** 按钮，它会尝试直接跳转到本 App 的电池优化设置页。如果跳转失败，就按上面的步骤手动搜。

### 第 2 步：允许通知（Android 13 及以上必做）

App 的保活靠一条**常驻通知**维持（安卓规定前台服务必须显示通知，否则会被系统杀掉）。

1. 第一次打开 App 时，系统会弹 **`允许 Dr.COM 校园网自动登录 发送通知？`** —— **必须点「允许」**。
2. 如果当时点了「不允许」，手动补开：`设置` → `通知`（或 `通知与状态栏`）→ `应用通知管理` → `Dr.COM 校园网自动登录` → 打开 **`允许通知`**，并确认「常驻通知」类别的开关也是开的。
3. 部分 ROM（如小米）还有 **`通知类别`** 里的独立开关，把「自动登录保活」这一类别也打开。

### 第 3 步：在最近任务里锁定 App

1. 打开最近任务界面（上滑停顿 / 按多任务键）。
2. 找到 **`Dr.COM 校园网自动登录`** 的卡片。
3. **长按**（小米/OPPO 部分版本）或 **下拉卡片**（华为），或点右上角 **`⋮`**（vivo/OPPO）。
4. 选择 **`锁定` / `加锁`**。
5. 卡片上出现 🔒 图标即成功。

## 症状对照表：保活没配好长这样

对着下表找你的症状，按「怎么改」操作。

| 症状 | 说明什么 | 怎么改 |
| --- | --- | --- |
| **「App 打开时能登录，关掉就不行」** | 自启动 / 后台活动没开，系统一退到后台就冻住了 | 回去做「自启动」和「电池优化白名单」两节，并把**省电策略设为「无限制」** |
| **「过一会儿就不检查了」（状态里的「上次检查」时间一直停在几小时前）** | 省电策略没设成「无限制」，或者开了省电模式 | 把省电策略改成 **`无限制`** / **`允许完全后台行为`**；关掉系统「省电模式」 |
| **「重启手机后不自动登录」** | **自启动**没开（这是最典型的自启动症状） | 打开 App 的自启动开关；华为/荣耀要**先关闭「自动管理」**再手动勾选那 3 项 |
| **「通知栏里没有那条常驻通知」** | ①「常驻通知保活」开关没打开；②通知权限被拒了 | ①App 里打开 `常驻通知保活`；②去 `设置 → 通知 → 应用通知管理` 里允许本 App 通知，然后重开一次保活开关 |
| **「通知有，但过一阵子还是断了」** | 通知被系统折叠/静音了，或 App 被「一键清理」清掉了 | 把本 App 的最近任务卡片 **锁定**；在手机管家的「一键优化」白名单里加入本 App |
| **「息屏一段时间后就掉线」** | 息屏休眠时系统断了 WiFi | 华为：`设置 → 电池 → 更多电池设置 → 休眠时始终保持网络连接` **打开**；其他品牌检查是否有「睡眠待机优化」并关闭 |
| **「清一下后台就得重新手动登录」** | 卡片没锁定，被一键清理杀掉了 | 按「通用三步」第 3 步锁定卡片 |
| **「App 图标/通知显示中文变成方块」** | 系统字体缺失，与保活无关 | 一般重启后恢复，可忽略 |

## 关于「一键优化 / 一键清理」

国产 ROM 的**手机管家**都有一个「**一键优化**」或「**一键加速**」按钮，它会：

- 结束「它认为不需要」的后台进程（包括你的自动登录 App）
- 释放内存

**它不认识你的 App 是「有用的后台服务」**，所以会照杀不误。

处理办法：把本 App 加入它的白名单。

| ROM | 大致路径 |
| --- | --- |
| 小米 | 手机管家 → 优化加速 →（设置）→ 锁定任务 / 白名单 → 加入「Dr.COM 校园网自动登录」 |
| 华为/荣耀 | 手机管家 → 清理加速 →（右上角设置）→ 忽略名单 → 加入本 App |
| OPPO/一加/realme | 手机管家 → 清理存储 / 一键清理 → 清理白名单 → 加入本 App |
| vivo/iQOO | i 管家 → 空间清理 → 清理白名单 → 加入本 App |

另外，**养成习惯：清理后台时不要把它的卡片一起划掉**（锁定了的话一般也划不掉）。

## App 里能帮你做什么

打开 App，下面这两处直接和保活相关：

### 「常驻通知保活」开关（自动化区域）

- **打开**：App 会启动一个**前台服务**，在通知栏显示一条常驻的静默通知（「Dr.COM 自动登录 / 正在守护校园网连接」）。
- 好处有两个：
  1. 让系统知道「这个 App 正在工作」，被杀掉的概率大幅降低；
  2. 它还能监听网络变化——**WiFi 一连上，立刻触发一次登录检查**（不用等下一个检查周期，这点很实用）。
- 看到这条通知**不要觉得烦**，它是保活的关键，请不要把它划掉。

### 「打开电池优化设置」按钮

- 点一下会自动跳转到本 App 的电池优化设置页。
- 进去之后选择 **`不优化`**。
- 如果跳转失败（部分 ROM 不允许直接跳转），App 会提示「无法打开电池优化设置」，此时按「通用三步」第 1 步手动搜索 `电池优化` 即可。

### 「检查间隔」下拉框

- 可选 **15 / 30 / 60 / 120 分钟**。
- 默认 **30 分钟**。
- 说明：安卓系统的后台定时任务（WorkManager）有**强制最小周期 15 分钟**的限制，即使设得更短也会被系统自动拉到 15 分钟。所以「15 分钟」就是最勤快的档位了。
- 想更实时？靠上面那条「常驻通知保活」——它在**网络恢复时**会立刻补一次检查，不用等周期。

## 配置完成后的自检清单

全部配完后，按下面 5 条确认一遍：

1. [ ] App 里「自动检查」开关 **已打开**，「检查间隔」已选好。
2. [ ] App 里「常驻通知保活」开关 **已打开**，通知栏能看到「Dr.COM 自动登录」的常驻通知。
3. [ ] 「连接状态」区域点「立即登录」后能显示 **已在线**。
4. [ ] 系统设置里，本 App 的 **自启动打开**、**省电策略无限制**、**电池优化不优化** 三项都确认过。
5. [ ] 最近任务里本 App 的卡片 **已锁定**（有 🔒 图标）。

最后：**锁屏放置 30 分钟**，再打开 App 看「连接状态」里的 **「上次检查」时间**。如果时间更新到了最近几分钟内，说明保活成功了 ✅。

如果时间还停在很久以前，回到症状对照表继续排查。
